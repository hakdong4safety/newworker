# 신규채용자 준수사항 온라인 작성 시스템

IPARK현대산업개발 · 학동 4구역 현장

손으로 쓰던 「신규채용자 준수사항」(Rev.5) 서류를 휴대폰·태블릿으로 작성하고,
사무실 컴퓨터에서 날짜·업체별로 모아 확인·출력하는 정적 웹 앱입니다.
빌드 도구나 서버 없이 **`index.html` 파일 하나**로 작동합니다.

---

## 빠른 시작

### GitHub Pages로 배포
1. 이 저장소를 그대로 두거나 fork 합니다.
2. **Settings → Pages → Branch: `main` / `root`** 선택 후 저장합니다.
3. 몇 분 뒤 `https://<사용자명>.github.io/<저장소명>/` 로 접속하면 바로 작동합니다.
4. 이 주소를 교육장 태블릿과 사무실 컴퓨터에서 **동일하게** 열어 사용합니다.

> **파일을 새로 올린 뒤에는 각 기기에서 강력 새로고침을 한 번 해 주세요.**
> Windows·안드로이드 `Ctrl+F5` / 맥·아이패드 `Cmd+Shift+R`.
> 브라우저에 예전 파일이 남아 있으면 바뀐 내용이 보이지 않습니다.

### 로컬에서 바로 확인
그냥 `index.html`을 더블클릭해 브라우저로 열면 됩니다. 인터넷 연결은
글꼴(Pretendard), PDF 저장 기능(html2canvas·jsPDF), 양식 변경 기능(SheetJS)을
처음 사용할 때만 필요합니다.

## 사용 흐름

```
[교육장 · 폰/태블릿]                      [사무실 · 컴퓨터]
근로자 작성 → 저장              →         관리자 접속 (비밀번호 0309)
                                          → 날짜·업체별 확인 → 출력 / PDF 저장
```

근로자는 **저장**까지만 진행합니다. 출력·PDF 저장은 관리자 화면에서 개별 건을
열어 컴퓨터로 처리합니다.

## 주요 기능

### 근로자 작성 (9단계)
- 인적사항 → 교육·경력 → 보건면담 → 생활습관 → 혈압 측정 → 서약·동의 →
  보호구 수령 → 최종 확인 → 저장
- **혈압 자동 판정** — 대한고혈압학회 기준 (정상/주의/고혈압전단계/고혈압/위기),
  140/90 이상이면 2차 측정 칸이 자동으로 열립니다
- **서명은 항목별로 각각** — 서약서 서명 1곳 + 보호구(안전모·안전화·안전벨트·기타)
  수령 서명을 받은 항목마다 따로 받습니다. 성명은 타이핑(관리·검색용)입니다
- **신분증 · 기초안전보건교육 이수증 · 혈압 측정지 사진** — 선택 사항. 준수사항
  양식에는 포함되지 않고, 별도의 **사진대지 문서**에 이름·날짜와 함께 자동으로
  채워집니다. 사진은 저장 용량 안에 들어오도록 화질·크기를 자동으로 줄입니다
- **공종 "기타" 직접입력** — 목록에 없는 공종은 자유롭게 입력
- **다국어** — 한국어 · Tiếng Việt · 中文 · ไทย (서약서 법적 문구는 한국어 원문 기준)
- **큰글씨 모드** — 시작 화면 스위치로 작성 화면 글자 확대
- **취약근로자 전용 양식** — 관리자가 취약근로자로 표시하면, 화면·인쇄·PDF가
  전부 상단에 빨간 "취약 근로자" 표시가 있는 전용 양식으로 자동 전환됩니다

### 관리자 탭 (비밀번호 `0309`)
- **실시간 자동 갱신** — 다른 기기(태블릿·컴퓨터)가 저장·수정·삭제하면
  **아무것도 누르지 않아도** 이 화면 목록에 바로 반영됩니다
- **↻ 다시 불러오기** — 실시간 연결이 끊겼을 때 쓰는 수동 버튼입니다.
  평소에는 누를 일이 없습니다
- **날짜별 제출** — 업체명 필터가 달린 표로 오늘(또는 지정한 날짜) 제출 목록 확인
  - 이름 클릭 → 근로자 양식/사진대지 상세 열람
  - **전체 복사** 열의 "V" 버튼 → 화면 전환 없이 그 자리에서 PDF 즉시 다운로드
  - **선택 삭제** — 체크박스로 여러 건을 골라 한 번에 삭제 (전체 삭제와 별개)
- **취약 근로자** 탭 — 체크된 근로자만 날짜와 무관하게 모아서 관리
- **준수사항 양식 / 사진대지** 두 문서를 탭으로 전환하며 각각 확인·출력·저장
- **화면 맞춤 / 크게 보기** — 양식 미리보기 위쪽 버튼으로 전환합니다.
  기본은 "화면 맞춤"(한 화면에 전부), 글씨를 자세히 볼 때는 "크게 보기"(원래 크기)
- **📄 PDF 저장** — 화면에 보이는 양식을 그대로 캡처해 A4 한 장 PDF로 저장
  (한가운데 정렬, 별도 프로그램 없이 바로 열어볼 수 있습니다)
- **🖨 출력** — 브라우저 인쇄창을 열어 종이로 출력
- **사진 나중에 첨부** — 저장이 끝난 뒤에도 근로자 상세 화면에서 신분증·이수증·
  혈압측정지 사진을 첨부·교체·삭제할 수 있습니다 (사진대지에 바로 반영).
  넓은 화면(가로 1100px 이상)에서는 양식 **오른쪽에 사진칸이 나란히** 붙고,
  좁은 화면에서는 양식 **아래쪽**에 나옵니다
- **양식 변경** — 새 엑셀(.xlsx)을 올리면 라벨 문구로 항목을 자동 인식해
  미리보기와 인식률 체크리스트를 보여준 뒤 적용
- **닫기 버튼**은 문맥에 따라 동작합니다: 근로자 양식을 보다가 닫으면 관리자
  목록으로, 관리자 탭 자체에서 닫으면 완전히 종료됩니다
- CSV / JSON 내보내기, 전체 삭제

### 공통
- **모바일 · 태블릿 · 데스크톱 겸용 반응형 레이아웃**
  | 화면 폭 | 배치 |
  |---|---|
  | ~759px (휴대폰) | 1단, 손가락 조작에 맞춘 크기 |
  | 760px~ (태블릿 세로) | 1단이지만 여백·글자·카드 확대 |
  | 1024px~ | 관리자 표가 가로 스크롤 없이 전부 보이고, 표 머리글 고정 |
  | 1120px~ (컴퓨터) | 작성 화면 **2단 배치**, 하단 버튼 우측 정렬 |
  | 1100px~ (양식 보기) | 사진 첨부칸이 양식 오른쪽 사이드바로 |
  큰글씨 모드에서는 글자가 크므로 2단 배치가 자동으로 해제됩니다.
- **인쇄·PDF는 원본 Rev.5 서식 그대로 A4 한 장, 한가운데 정렬**

> **엑셀(.xlsx) 파일로 내보내는 기능은 없습니다.** 서식이 그대로 유지되는
> PDF 저장을 기본으로 사용하세요. (관리자 탭의 "양식 변경"은 새 엑셀 서식을
> *읽어들이는* 기능이며, 내보내기와는 무관합니다.)

> **PDF 저장은 처음 사용할 때 인터넷 연결이 필요합니다.** 화면을 그대로 찍는
> 도구(html2canvas·jsPDF)를 그때 한 번 내려받습니다. 연결이 안 되면 안내
> 메시지가 뜨며, 대신 **🖨 출력 → "PDF로 저장"**을 쓰시면 됩니다.

## ⚠️ 배포 전 반드시 확인할 것 — 데이터 저장 범위

이 앱은 다음 순서로 저장소를 사용합니다.

1. **Firebase Firestore** — `index.html` 안의 `FIREBASE_CONFIG`에 값을 채우면 사용됩니다.
   설정하면 **모든 기기(태블릿·컴퓨터)가 실시간으로 데이터를 공유**합니다.
   (Firestore 실시간 수신 `onSnapshot`을 씁니다. 처음 한 번만 전체를 받고
   그 뒤로는 바뀐 건만 오므로 통신량이 적고, 끊겨도 자동으로 다시 붙습니다.) 무료로
   충분합니다. 설정 방법은 **`Firebase_설정_가이드.md`**를 그대로 따라 하세요
   (처음부터 끝까지 클릭 단위로 안내되어 있습니다).
   - 제출 기록은 **근로자 1명당 문서 1건**으로 따로 저장됩니다 (Firestore의
     문서당 1MB 용량 제한을 넘지 않도록 하기 위함입니다). 사진이 있어도
     한 건당 보통 1MB를 넘지 않도록 자동으로 압축됩니다.
   - 저장·수정·삭제는 **바뀐 1건만** 서버에 반영합니다. 사진 한 장을 붙일 때
     전원 기록을 다시 올리지 않으므로, 인원이 늘어도 느려지지 않고 무료
     사용량도 거의 쓰지 않습니다.
   - 기록마다 눈에 보이지 않는 고유 번호(`uid`)가 붙어 있어, 두 태블릿이
     **같은 순간에 저장해도 서로를 덮어쓰지 않습니다.**
   - 서류에 찍히는 **관리번호(HD4-…)의 순번은 서버에서 하나씩 받아 옵니다.**
     여러 태블릿을 동시에 써도 같은 번호가 두 장 나오지 않습니다.
     (서버에 못 닿으면 그 기기 기준으로 매기며, 이때만 번호가 겹칠 수 있습니다.
     번호가 겹쳐도 자료는 각각 따로 안전하게 남습니다.)
   - 날짜 구분은 **작성한 기기의 그날 날짜**를 값으로 저장해 씁니다. 기기 시간대가
     서로 달라도(예: 외국인 근로자 폰이 본국 시간) 같은 날짜로 묶입니다.
2. Claude 아티팩트 환경의 공유 저장소(`window.storage`) — Firebase 미설정 시,
   Claude 안에서 실행 중이면 사용
3. 브라우저의 `localStorage` — 1, 2가 없으면 사용 (이 기기에만 저장됨,
   기기 저장공간이 가득 차면 저장이 실패할 수 있습니다)
4. 메모리 — 1~3 모두 없으면 새로고침 시 사라짐

**저장이 실패하면 화면에 반드시 오류 메시지가 뜨고, "저장되었습니다" 화면으로
넘어가지 않습니다.** 조용히 실패하는 경우는 없습니다. 사진 첨부·삭제,
취약근로자 체크도 마찬가지로, 실패하면 값이 원래대로 되돌아가고 사유가 표시됩니다.

**GitHub Pages처럼 별도 백엔드가 없는 정적 호스팅에서 여러 기기의 데이터를
한 곳에서 보려면 반드시 1번(Firebase)을 설정해야 합니다.** 설정하지 않으면
기기(브라우저)별로 데이터가 따로 저장되어, 태블릿에서 작성한 내용이 사무실
컴퓨터의 관리자 화면에 자동으로 나타나지 않습니다.

### 화면 위쪽 배지 읽는 법

관리자 탭을 열면 배지가 **실제로 서버를 읽어 본 결과**를 알려 줍니다.
건수까지 같이 나오므로, 다른 기기와 다르게 보이면 여기부터 확인하세요.

| 배지 | 뜻 | 할 일 |
|---|---|---|
| ☁ 실시간 연결됨 · N건 | 정상 (자동 갱신 중) | — |
| ☁ 서버에서 N건 불러옴 | 정상 (수동으로 받아 온 상태) | — |
| ⚠ 서버에 N건이 있는데 화면에는 M건입니다 | 페이지를 연 뒤 다른 기기가 새로 올림 | **↻ 다시 불러오기** |
| ⚠ 화면 자료가 오래되었습니다 | 열 때 연결이 끊겼다가 지금 붙음 | **↻ 다시 불러오기** |
| ⚠ 서버에 연결하지 못했습니다 | 인터넷·사내망 차단 | 연결 확인 후 다시 불러오기 |
| 💾 이 기기에만 저장 | Firebase 미설정 | `Firebase_설정_가이드.md` 참고 |

> **한 기기에서는 보이는데 다른 기기에서는 안 보일 때**
> 정상이라면 실시간 연결이 알아서 맞춰 줍니다. 그래도 안 맞으면 배지를
> 확인하세요. 초록불이 아니면 그 기기의 인터넷이 끊긴 것이므로,
> 연결을 복구한 뒤 **↻ 다시 불러오기**를 누르시면 됩니다.

### 지금 당장 Firebase 없이 여러 기기에서 모아 보려면
각 태블릿에서 하루 업무가 끝날 때 관리자 탭 → **JSON 백업**을 내려받고,
사무실 컴퓨터에서 그 JSON들을 모아 확인하는 방식을 임시로 병행하세요.

## 커스터마이징 메모

- 기본 양식(일반 / 취약근로자 / 사진대지) 데이터는 `index.html` 안에
  `DEFAULT_TEMPLATE` / `RISK_TEMPLATE` / `PHOTO_BOARD_TEMPLATE` 상수로 이미
  내장되어 있습니다. 원본 엑셀을 다시 반영하려면 관리자 탭의 **양식 변경**
  기능으로 새 파일을 올리고 적용하면 됩니다 (준수사항 양식에만 적용되며,
  사진대지·취약근로자 전용 양식은 코드 내 내장본을 그대로 사용합니다).
- 관리자 비밀번호는 `const ADM_PW = "0309";` 한 줄로 되어 있습니다. 필요하면
  코드에서 직접 바꾸세요 (별도 로그인 서버는 없으므로 강력한 보안은 아닙니다 —
  민감 정보 보호는 파일 접근 자체를 제한하는 방식과 병행하세요).
- 다국어 문구는 `I18N` 객체(`ko`/`vi`/`zh`/`th`)에 모여 있습니다. 번역은
  실무 검수를 한 번 거치는 것을 권장합니다.
- 사진 압축 목표 용량은 `compressImage(file, maxW, targetBytes)` 호출부의
  `targetBytes` 값(기본 190000 ≈ 190KB)을 바꿔 조정할 수 있습니다.
- 화면 폭별 배치는 CSS 맨 아래 "태블릿 · 데스크톱 레이아웃" 구역에 모여
  있습니다. 본문 폭은 `--shell`(작성 화면) / `--shell-wide`(관리자 화면)
  변수로 조절합니다. **컴퓨터에서 2단 배치가 불편하면**
  `@media (min-width:1120px)` 안의 `.step.on{display:grid…}` 한 줄만
  `display:block`으로 바꾸면 1단으로 돌아갑니다.
- 양식 자동 축소의 하한선은 `fitSheetView()` 안의 `hFit >= 0.45` 입니다.
  이 값보다 더 작아져야 화면에 들어오는 상황이면, 축소 대신 세로 스크롤을
  쓰도록 되어 있습니다 (글씨가 뭉개지는 것을 막기 위함).

## 알려진 제약

- PDF 저장은 화면을 이미지로 찍는 방식이라, PDF 안의 글자를 복사하거나
  검색할 수는 없습니다. 서식이 원본과 100% 같게 나오는 쪽을 우선했습니다.
- 관리자 비밀번호는 파일 안에 그대로 들어 있어, 파일을 받아 열어보면 알 수
  있습니다. 외부에 공개되면 안 되는 주소라면 GitHub Pages를 비공개 저장소 +
  사내망으로 옮기는 것을 검토하세요.
- 인터넷이 완전히 끊긴 환경에서는 글꼴이 기본 글꼴로 바뀌고, PDF 저장과
  양식 변경(엑셀 읽기)이 동작하지 않습니다. 작성·저장·인쇄는 정상입니다.
